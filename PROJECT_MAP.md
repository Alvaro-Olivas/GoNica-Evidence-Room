# Project Map

## GoNica Brain
The reasoning, planning, governance, evidence, continuity, and decision layer.

Primary responsibilities:
- analyze CRM exports and company files
- preserve important customer history and relationships
- classify fields and identify missing information
- generate migration maps, field registries, tag registries, workflow plans, and implementation blueprints
- maintain authority, testing state, approvals, recovery, and auditability

## GoNica Marketing
The reusable implementation and packaging layer.

Primary direction:
- repeatable client onboarding
- CRM migration and cleanup
- workflow and knowledge deployment
- reusable installation packages / snapshots
- ongoing optimization and controlled automation

## GoNica Tours
The first real operating proof environment.

Used to exercise:
- website and destination systems
- supplier research and intake
- contact and campaign systems
- CRM structures
- automation patterns
- operational documentation

## GoHighLevel
GoHighLevel is currently an execution environment, not the definition of GoNica.

The architecture intentionally keeps the company model and reasoning layer separate from any one CRM so execution tools can be changed without rebuilding the entire business brain.
